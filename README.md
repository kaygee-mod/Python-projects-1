2. University Email Generator
A Python program that creates a university email address based on the user’s first and second names.

The program asks the user for their first name and surname, combines them to create a username, and generates an email address using the university domain.
Example:

Enter your first name: John

Enter your surname: Smith

Your email is johnsmith@luouniversity.co.za
Concepts Practised:

User input

String manipulation

Variables

String concatenation

Formatted output

3. Python Guessing Game
A simple guessing game where the user must guess the secret programming language.

The secret word is Python. The program continues asking the user:

What is the programming language you are using?

If the user enters the correct answer, the program displays a success message. If the answer is incorrect, the program tells the user to try again.
Example:

What is the programming language you are using? Java

Incorrect guess, try again.

What is the programming language you are using? Python

Correct! You guessed correctly.
Concepts Practised:

while loops

if statements

User input

String comparison

Boolean conditions
